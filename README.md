# 💔 Mind Map Penyakit Sosial — PAI

Website mind mapping interaktif materi **Penyakit Sosial di Kalangan Remaja** (Pendidikan Agama Islam),
dengan animasi hati melayang, kustom kursor, garis mind map yang tergambar sendiri, dan navigasi antar halaman.

## 🚀 Deploy ke GitHub Pages
1. Buat repository baru, misal `mindmap-penyakit-sosial`
2. Upload semua file ini (struktur folder dipertahankan)
3. Settings → Pages → Source: `main` branch, folder `/ (root)`
4. Simpan, lalu buka `https://USERNAME.github.io/mindmap-penyakit-sosial/`

## 📂 Struktur
- `index.html` — Mind map interaktif utama (klik cabang untuk berpindah halaman)
- `pengertian.html`, `jenis.html`, `penyebab.html`, `dampak.html`, `islam.html`, `refleksi.html`
- `css/style.css` — Semua gaya & animasi
- `js/main.js` — Partikel hati, kursor, reveal, efek klik
- `js/mindmap.js` — Logika mind map SVG

## 💖 Fitur
- Partikel hati & bintang melayang (canvas)
- Garis mind map tergambar otomatis + node mengambang
- Efek ledakan hati saat tombol diklik
- Kursor kustom glow, aurora background, glassmorphism
- Fully responsive (mode kartu di HP)
